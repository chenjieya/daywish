## 1. 版本与使用

Windows 和 macOS 启动后直接在后台运行，不自动弹出主窗口。Windows 不显示任务栏按钮，通过系统托盘打开；macOS 不显示 Dock 图标，通过菜单栏打开。关闭窗口后继续运行，退出仍使用托盘或菜单栏的退出入口。

Windows 显式打开界面时可恢复已最小化窗口；托盘不可用时显示窗口并恢复任务栏入口。macOS 沿用 `LSUIElement` 和 accessory 应用策略。此次没有改变个人设置、软件更新源及窗口位置保存方式。

v0.3.0 已正式发布，因此本次递增为 v0.3.1，不覆盖旧版本安装包或移动既有标签。已安装 v0.3.0 的用户可从软件内检查更新；更早版本可从官网下载安装。
