## 1. 行为修正

用户要求软件驻留后台、任务栏或 Dock 不显示图标，同时桌面内容面板可见。v0.3.1 将面板一并隐藏，未满足该要求。v0.3.2 启动即显示桌面内容面板，保留托盘或菜单栏驻留方式。

Windows 保留 `skipTaskbar: true`，页面就绪后调用 `showInactive()`，显示面板但不抢当前应用焦点；托盘不可用时保留任务栏操作入口。macOS 保留 `LSUIElement` 和 accessory 策略，使用 `orderFront(nil)` 显示面板，不主动激活应用。

这里的后台驻留不调用操作系统的窗口最小化；同一个窗口一旦真正最小化，其内容也会隐藏。用户主动点击关闭时仍沿用原有收起行为，可从托盘或菜单栏重新打开。

Windows 运行检查发现初始导航前锁定视觉缩放会遇到 frame 被替换，现将初始化移至页面就绪时执行，并处理异步错误。

## 4. 软件更新网络说明

本机 v0.3.0 更新失败已用隔离 Electron 进程复现：系统代理 `127.0.0.1:7890` 访问官网更新清单超时或返回 `ERR_CONNECTION_CLOSED`；同一请求在隔离诊断进程直连时返回 HTTP 200，实际更新器成功发现 v0.3.1。诊断没有修改系统代理、已安装软件或执行安装。

这说明本机检查阶段失败来自代理连接，不能根据旧通用提示认定为磁盘不足。需要在代理软件将 `daywish.alvis.org.cn` 设置为直连后重新检查；安装包仍使用正式 GitHub 下载地址，可保留其原有代理规则。本次版本仅修正桌面面板显示，没有改变软件的代理设置。
