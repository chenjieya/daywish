## 1. 支持范围

用户设备为 Apple M 系列、macOS 12.x。本次发布 Apple Silicon `arm64` 安装包，应用最低要求为 macOS 12.0；本轮没有发布 Intel 安装包。旧版 v0.3.2 及之前要求 macOS 26，不能作为 Monterey 兼容包使用。

| 系统 | 材质与登录项 |
|:--|:--|
| macOS 12 | `NSVisualEffectView` 原生浅色磨砂；在系统偏好设置的“用户与群组 → 登录项”手动添加应用 |
| macOS 13–15 | 原生浅色磨砂；软件内支持设置开机启动 |
| macOS 26 及以上 | `NSGlassEffectView` 原生液态玻璃；软件内支持设置开机启动 |

面板仍在启动时显示，软件驻留菜单栏，Dock 不显示图标。工资日、日历更新、软件更新、窗口位置与个人偏好继续保留。原生新系统材质使用运行时版本判断，旧系统不访问不存在的类型；macOS 13 登录项 API 亦经过版本判断。

## 2. 构建与更新源

Swift Package、应用 `LSMinimumSystemVersion` 和部署目标统一为 `12.0`。现有 Sparkle 2.10.1 自身最低要求为 macOS 12，无需引入新的更新依赖。

构建后扫描应用包内所有 Mach-O，读取 `LC_BUILD_VERSION` 或 `LC_VERSION_MIN_MACOSX`，核对主程序及所有更新框架、辅助程序的最低版本不高于 12.0。应用只修改 Info.plist、但嵌入组件仍要求新系统的情况会被拒绝发布。

云端使用稳定 `macos-26` 构建环境；SDK 26 可构建兼容包，SDK 27 构建时才编译其专属交互效果。构建工具的版本要求与用户运行应用的系统要求分别核对，不要求用户升级系统或安装 Xcode。

装配后的应用分别启动液态玻璃和强制旧版磨砂界面，检查资源、面板可见性与 Sparkle 初始化。该检查在现代 macOS runner 上执行，不能替代用户 macOS 12 真机验收。

发布记录新增可选 `minimumSystemVersion` 字段，新包为 `12.0`；历史包缺省仍按 `26.0` 处理。官网和 Sparkle appcast 按每个实际发布包显示最低系统要求，避免将旧版不兼容包误推给 Monterey。

## 4. 安装与验收

从 [Mac v0.3.3 发布页](https://github.com/chenjieya/daywish/releases/tag/macos-v0.3.3) 下载 `Daywish-0.3.3-macOS-arm64.zip`，解压后将“好日将至.app”放入“应用程序”。正式下载已开放，官网同步完成。

macOS 12 需首次手动安装此兼容版本。后续软件更新通过菜单栏“检查软件更新”或设置内入口操作。应用使用临时应用签名与独立更新包签名，不是 Apple Developer ID 公证版本。

用户设备需确认：应用能打开、磨砂面板和文字清晰可见、Dock 无图标、菜单栏可打开和退出、设置保存及日历刷新正常。开机启动在 macOS 12 通过系统登录项手动设置。
